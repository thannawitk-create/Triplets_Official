# 📁 โฟลเดอร์ Public (TRIPLETS Band Website)

โฟลเดอร์นี้ใช้สำหรับวางไฟล์เพลง MP3 และไฟล์รูปภาพจริง เพื่อให้โปรเจกต์สามารถเปิดฟังและแสดงผลบน Vercel หรือเว็บไซต์จริงได้ทันที

---

### 🎵 1. วิธีวางไฟล์เพลง MP3 (`/public/audio/`):
วางไฟล์เพลง MP3 ของคุณลงในโฟลเดอร์ `public/audio/` โดยตั้งชื่อไฟล์ตามหมายเลขแทร็กดังนี้:
- `track-1.mp3` : เพลง หากวันนั้น... (If That Day...)
- `track-2.mp3` : เพลง ความรักที่หายไป (Lost Love)
- `track-3.mp3` : เพลง รักที่ไม่ได้พูด (Unspoken Love)
- `track-4.mp3` : เพลง เพราะขาดเธอ (Without You)
- `track-5.mp3` : เพลง คิดถึงเธอเสมอ (Always Missing You)
- `track-6.mp3` : เพลง วันที่ไม่มีเธอ (Days Without You)
- `track-7.mp3` : เพลง เสียงในใจ (Echoes Inside)
- `track-8.mp3` : เพลง ก้าวต่อไป (Moving Forward)

*(เมื่อวางไฟล์ครบแล้ว เว็บไซต์บน Vercel จะเล่นไฟล์ MP3 จริงทันที 100%)*
