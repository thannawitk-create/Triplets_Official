# โฟลเดอร์รูปภาพ (Images Directory)

คุณสามารถนำไฟล์รูปภาพของวงคุณมาวางในโฟลเดอร์นี้ หรือสามารถเข้าสู่ระบบ Admin บนหน้าเว็บเพื่อคลิกเปลี่ยนและอัปโหลดรูปภาพ (JPG, PNG, WEBP) ได้โดยตรงผ่านระบบ Drag & Drop ครับ

### รายการรูปภาพที่แนะนำ:
- `band_logo.png` / `band_logo.jpg` - โลโก้วง (แนะนำ 400x400 หรือไฟล์ PNG โปร่งใส)
- `hero_banner.jpg` - แบนเนอร์เวทีหลัก (แนะนำ 1920x1080 หรือ 1280x720)
- `album_cover.jpg` - ปกอัลบั้ม (แนะนำ 1000x1000 สัดส่วน 1:1)
- `win.jpg` - รูปนักร้องนำ / สมาชิก 1 (สัดส่วน 3:4)
- `ten.jpg` - รูปมือเบส / สมาชิก 2 (สัดส่วน 3:4)
- `tiger.jpg` - รูปมือกลอง / สมาชิก 3 (สัดส่วน 3:4)
- `mona.jpg` - รูปศิลปินรับเชิญ / สมาชิก 4 (สัดส่วน 3:4)
